# 🏦 Sistema de Gerenciamento de Contas Bancárias

## 📋 Descrição do Projeto

Sistema desenvolvido em Java Swing para gerenciamento de informações de contas bancárias, permitindo consulta e atualização de dados de clientes.

## 🚀 Funcionalidades

- **Cadastro de informações bancárias** (agência e conta)
- **Gestão de dados pessoais** (nome, endereço, telefone e CPF)
- **Seleção de tipo de conta** (Corrente ou Poupança)
- **Operações básicas**: Consultar, Atualizar e Fechar

## 🛠️ Tecnologias Utilizadas

- **Java SE** - Linguagem de programação
- **Java Swing** - Framework para interface gráfica
- **AWT** - Abstract Window Toolkit para componentes gráficos

## 📦 Estrutura do Projeto
src/
└── telas/
└── Janela.java

## ⚙️ Como Executar

### Pré-requisitos
- JDK 8 ou superior
- IDE Java (Eclipse, IntelliJ, NetBeans) ou compilador via terminal

### Compilação e Execução

1. **Clone o repositório**:
```bash
git clone https://github.com/anajuca/CadastroBanco_POO
```
2. **Compile o projeto**:
```bash
javac -d bin src/telas/Janela.java
```
3. **Execute a aplicação**:
```bash
java -cp bin telas.Janela
```
